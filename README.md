# 🎬 Movie Recommendation System

A movie recommendation web application built with **Python and Streamlit** that recommends the top 5 similar movies based on a user's selected movie. It uses a similarity matrix and the **TMDB API** to fetch movie posters and deliver an interactive recommendation experience.

## Features

- Recommends the top 5 similar movies
- Similarity matrix-based recommendations
- Movie posters fetched using the TMDB API
- Interactive Streamlit interface

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- Scikit-learn
- TMDB API

# Installation

```bash
git clone https://github.com/getcloselyai-ctrl/Movie-Recommendation-System.git
cd Movie-Recommendation-System
pip install -r requirements.txt
streamlit run app.py
```

# API Configuration

Obtain an API key from [The Movie Database (TMDB)](https://www.themoviedb.org/), then configure it as required by your application.
